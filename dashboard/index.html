Где забирать

Объявления отсюда и те, что продавец готов отправить (bpost и т. п.), ИИ проверяет первыми. Далёкие «только лично» ИИ оценивает на 1–2 балла ниже.

Объявления, в названии которых есть «мусорное» слово, отбрасываются без ИИ (экономит лимит). Если в названии есть слово-исключение — объявление всё равно идёт к ИИ. По одному слову/регулярному выражению в строке; ищется часть слова, регистр не важен (kitten, \bbieden\b, canap[ée]). Два словаря: NL и FR.

Кнопка «Проверить сейчас»

Кнопка запускает GitHub Actions. Ей нужен токен GitHub — он хранится в базе дашборда и общий для обоих пользователей, вводить его нужно один раз. Создай его: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate: Repository access — Only select repositories → be-free-finder, Permissions → Repository → Actions: Read and write.
