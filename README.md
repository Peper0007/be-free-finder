# Бесплатные находки в Бельгии для Etsy/eBay → Telegram

Каждый час (в :41) робот на GitHub Actions:
1. берёт новые бесплатные объявления с **2dehands.be / 2ememain.be** (одна площадка на двух языках, все полезные категории),
   дешёвые (до 5 €) в категориях антиквариата и коллекций, и всё новое с **Donnerie.be**;
   по желанию — бесплатные с **Marktplaats.nl** (выключено по умолчанию);
2. отсеивает очевидный мусор по словам — два словаря, **NL** и **FR** (`finder/prefilter.py`):
   животные, мебель, стройматериалы, детское, сломанное (`defect`, `kapot`, `HS`, `en panne`),
   «предложите цену» (`bieden`, `faire offre`), услуги;
3. показывает фото и текст нейросети **Gemini** и спрашивает: можно ли это продать на Etsy/eBay;
4. всё с оценкой 6/10 и выше присылает в **Telegram** — фото, что нашлось, примерная цена, город, ссылка,
   готовое сообщение продавцу на нидерландском или французском.

Дом — **Брюссель** (индексы 1000–1999 и коммуны вокруг): такие объявления и те, что продавец отправит bpost,
ИИ проверяет первыми; далёкие «только лично» оценивает на 1–2 балла ниже.

## Секреты (Settings → Secrets and variables → Actions)

| Name | Value |
|---|---|
| `TELEGRAM_TOKEN` | токен бота (тот же, что у болгарского) |
| `TELEGRAM_CHAT_ID` | ID канала (Actions → Run workflow → mode **chat-id**) |
| `GEMINI_API_KEY` | ключ из AI Studio, проект **be-free-finder** (свой дневной лимит) |
| `FIREBASE_SERVICE_ACCOUNT` | JSON ключа сервисного аккаунта Firebase проекта **be-free-finder** |

## Дашборд — https://be-free-finder.web.app

Вход через Google (правила — `firestore.rules`). Разделы и настройки те же, что у болгарского бота:
находки, забранные, учёт продаж, настройки источников, фильтры слов NL/FR, критерии ИИ, запуски и лимиты.
Дашборд (`dashboard/`) деплоится автоматически workflow `deploy-dashboard.yml`.
После правки значений по умолчанию в Python запусти `python scripts/gen_defaults.py`.

## Источники, которые проверены и не подключены

- **Hoplr**, **Facebook** (группы GIFT, Marketplace) — только после входа в аккаунт.
- **Freecycle** — объявления видны только участникам групп.
- **Geev**, **Donnons.org** — объявления для Бельгии на сайте не показываются (только в приложении).
- **Gratis-af-te-halen.be**, **Toutdonner.be** — сайты не открываются.
- **aDonner.be** — работает, но объявлений единицы (9 на всю Бельгию).
